# 脱出マップの拡充記録（2026年10月27日）

既存28作品へ32作品を追加し、公開カタログを60作品へ拡充した。作者の条件と原本を照合し、本番ARMホストの複製で複数人接続・保存再開・原本不変を確認した。採用一覧を本資料、結果を[受入確認](custom-maps-verification.md)と[実機証跡JSON](custom-maps-verification-20261027.json)に記録する。

## 調査と選定

サブエージェントでクラフターズコロニーのJava版「脱出・謎解き」を分担調査した。通算人気の既存採用範囲より先も調べ、作者の配布ページ、仕様画像、同梱README、原本の保存版を突合した。

| 段階 | 件数 | 内容 |
| --- | ---: | --- |
| 既存公開作品 | 28 | コロニー15作品、プラム太郎の群れ13作品 |
| 分担調査で整理した候補 | 69 | 既存作品との重複、対応条件、取得方法を確認 |
| 原本取得を試みた新規候補 | 40 | マルチ対応と正確なMinecraft版を条件として選定 |
| 原本の取得・登録に成功 | 37 | 公開や実機検証の合格を意味しない |
| 今回の実機検証対象 | 35 | 追加32作品と差し替え用の予備候補 |
| 追加公開作品 | 32 | 既存分と合わせて60作品 |

シングル専用、マルチ非対応、ForgeやOptiFineが必須の作品は今回の対象から外した。難易度、時間、ホラー等の要素は作者の記載を根拠とし、不明値を推定で埋めない。作者の対応人数と本サーバーで案内する人数を分け、少人数向けの作品を一律4人対応としない。

短編の選択肢として「廃れた図書館からの脱出」「時渡りの谷」「時の館」「幽霊少女と謎の屋敷」などを加える。「協力して怪しい研究所から脱出せよ」「夢からの脱出」「ハコビテの庭」は2人用の条件で登録・検証する。「胡蝶と夢」「奇妙なマンションからの脱出」などは作者条件に合わせて上限3人とする。

## 原本取得と条件の補完

外部配布先の一覧や確認画面を起動のたびにたどらないよう、次の3作品は作者の公開導線から特定した原本ファイルを`download_page`に固定した。

| 雨天の遺跡からの脱出 | [雨天の遺跡_ver.1.00.zip](https://drive.google.com/file/d/1CQm4HrnzblSkYtYyQq9myj7VaIH4onte/view) | 作者からリンクされる公開Driveフォルダ内のZIPを特定 |

原本の`level.dat`から保存版を取得し、作者指定の正確なMinecraft版と照合した。専用パックは`assets/`を含む実体と作者の指定を確認し、データパックの`pack.mcmeta`だけを根拠にリソースパックと判定しない。展開済み原本は非公開のサーバー領域に保存し、原本ZIP・ワールド・パックをGitへ登録しない。版、改訂、配布元と取得時のSHA-256を記録し、原本はプレイ用複製から分離する。正常登録後の取得用ZIPは容量確保のため削除する。

配布ページにない導入条件はREADMEから補完した。「夢からの脱出」は全員OP、動物スポーン、各自のパック導入と操作上の注意が必要である。「雨宿りの夜」「雪夜狂談」はOPを持つプレイヤーが1人以上必要であり、推奨難易度はそれぞれイージー、ノーマルである。両作品はMOB・動物・村人が存在できる設定を維持し、ピースフルへ変更しない。その他の作品も作者指定の`server.properties`、距離、OP条件をカタログへ補完した。

## 検証と検索の対応

検証用クライアントと検証スクリプトは作品ごとの人数に対応する。2人専用作品へ4人を強制接続せず、上限3人の作品もその人数で検証する。接続確認だけでなく、正常停止、保存した検証スコアの再開後の一致、原本の不変を確認する。

保存スコアは従来の`world/data/scoreboard.dat`と26.1以降の`world/data/minecraft/scoreboard.dat`に対応する。新形式が存在する場合は新形式を優先し、不正な新形式データを旧形式の値で成功扱いにしない。保存先変更は[Minecraft 26.1の公式リリースノート](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-1)と原本複製の実ファイルで確認した。

Minecraft版の検索は対応版が24種類を超えた場合にテキスト入力へ切り替える。「指定なし」を含むDiscordの選択肢25件上限によって検索可能な版が欠落しないようにする。

人による謎解きの完走、描画、音声、パック適用後の見え方、長時間の試遊は未実施である。合成クライアントの接続・保存再開が成功しても、これらを確認済みとは扱わない。

## 実機検証結果

35候補を実機検証し、最終的に35候補が合格した。26.1系の2作品は保存データ自体が正常であることを確認し、検証器の保存先対応後に初回接続から再検証して合格した。このうち選定順の32作品を採用した。

- 追加32作品は作者条件内の2～4人で初回接続と再開接続を確認した。
- 2人用3作品は2人、上限3人の3作品は3人で検証した。
- 正常保存後・再開後の検証スコア117を確認し、原本level.datのSHA-256が変わらないことを確認した。
- 既存28作品と追加32作品の計60作品を公開対象とする。内訳はコロニー47作品、プラム太郎の群れ13作品である。
- 単体テスト169件（Windowsでは1件skip）とruffが成功した。版検索の上限超過、不正人数の個別失敗、新旧の保存形式を回帰テストへ追加した。

実機証跡は[JSON](custom-maps-verification-20261027.json)に記録した。謎解き完走・描画・音声・パックの見え方は実プレイヤーによる未確認項目として残す。
